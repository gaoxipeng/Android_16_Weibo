# Android_16_Weibo

基于 Jetpack Compose 的非官方微博 Android 客户端，以原生信息流、媒体查看和液态玻璃控件为主要界面。登录与部分网页功能依赖微博服务。

当前版本：**20261022（50）**。最低支持 **Android 16 / API 36**。

## 下载与安装

从 [GitHub Releases](https://github.com/gaoxipeng/Android_16_Weibo/releases/latest) 下载 `app-release.apk`。

使用相同签名的新版 APK 可以覆盖安装。若系统提示签名不一致，不要直接卸载：卸载会清除本地账号、草稿和设置，请先确认安装包来源。应用不要求关闭系统的安全检查。

## 使用指南

应用内也可通过「我的 → 设置 → 使用说明」查看。

### 开始使用与账号

- 首次使用请进入「我的 → 设置 → 账号管理」完成微博网页登录。
- 账号管理可添加、切换和删除已保存账号；切换后按新账号重新加载数据。
- 微博接口需要有效登录态；遇到登录失效提示时，请重新登录后刷新。

### 底部导航与首页

- 底部依次为信息流、消息、搜索、写微博、我的。
- 长按第一个小房子图标，可切换「最新微博、好友圈、我的收藏、我的赞、热门、同城」，下方文字显示当前选择。
- 下拉刷新当前信息流，接近列表末尾时自动加载更多；刷新成功会显示更新条数提示。
- 「自动隐藏底栏」开启时，上滑隐藏、下滑显示；关闭后滚动时保持显示。进入设置和编辑等页面时底栏会隐藏。
- 首页连续按两次返回可退出应用。

### 微博卡片与返回

- 点击正文或卡片空白进入该条微博详情；点击被转发的浅灰卡片进入原微博详情。
- 点击彩色的 @昵称、话题或链接，分别打开用户主页、话题搜索或对应链接；普通正文不作为用户链接。
- 卡片右上角菜单支持跳转到微博、分享及收藏/取消收藏；自己的微博还可删除。
- 详情页与个人主页支持从屏幕中间向右拖动返回；未达到返回条件时会回到当前页。
- 微博链接和超话会按链接类型处理，部分链接可唤起官方微博；未安装或无法处理时使用网页。

### 评论、转发与点赞

- 详情页可左右切换「评论、转发」，评论页可选择按热度或按时间排序；点击评论标签可刷新评论。
- 上滑时头像和评论标签栏保持在顶部，内容继续滚动；详情页下拉可刷新。
- 单击赞可查看点赞用户；长按赞可点赞或取消点赞，已点赞时显示红色与拇指图标。
- 长按评论入口可写评论，长按转发入口可写转发；空白转发会自动使用「转发微博」。
- 评论支持表情、图片、@提及、楼中楼回复以及普通网址、短链接和微博正文等链接。
- 原作者评论的昵称后显示「博主」；设置中可控制是否显示评论点赞数量。

### 个人主页：微博、相册、视频、赞过

- 「我的」和用户主页提供「微博、相册、视频、赞过」四个标签，可点击或左右滑动切换。
- 微博展示该用户发布的内容；相册展示照片，视频单独展示；媒体列表接近底部时继续加载。
- 「赞过」请求正在查看的用户公开可见的点赞微博，支持下拉刷新和分页；可见范围受微博接口及隐私设置限制。
- 视频页点击封面会进入所属微博详情，并播放对应视频。
- 相册点击照片查看大图；左右切图后关闭，会按需要定位对应缩略图。惯性滚动中首次点击仅停止滚动。
- 头像与封面可放大查看；点击关注、粉丝统计可进入列表，访问其他用户时可关注或取消关注。

### 图片查看与保存

- 点击图片查看大图，多图可左右切换；支持双指缩放、拖动以及下拉关闭。
- 「查看图片」文字入口同样可打开图片；长按图片或大图可使用保存、保存全部、分享等菜单。
- 高清图未完成时先显示已有预览；加载速度与原图大小、网络和微博服务器有关。
- 支持的动态照片可在大图中查看动态效果，保存结果受原始媒体格式及系统相册支持情况影响。

### 视频播放与手势

- 点击播放按钮在卡片内播放，不自动展开控制条；单击播放画面可显示或隐藏控件。
- 双击视频卡片可进入浮窗；卡片长按支持预览和后续手势操作。
- 播放控件可切换全屏、浮窗、保存视频及拖动进度；浮窗的全屏按钮在左上角。
- 点击倍速可选择 0.5、0.75、1、1.5、2、3 倍速；全屏和浮窗中长按临时以 2 倍速播放，松手恢复。
- 从播放中的微博进入该条详情会衔接播放；全屏退出后回到原卡片。
- 详情页视频曾进入可视区域后，上滑使视频顶部到达顶栏边缘时可自动转为浮窗；滑回卡片可恢复卡片内播放。长正文中尚未看到的视频不会因此自动浮窗。
- 首页视频滚出可视区域会停止播放；是否允许切到系统后台继续出声，由「后台播放声音」设置控制。
- 旧视频地址失效时会尝试重新获取；视频可用性仍取决于来源和网络。

### 搜索

- 搜索框左侧可切换搜微博或搜用户；输入时显示联想词，微博结果可选择综合或实时排序。
- 点击热搜词条使用微博搜索，点击 #话题# 可进入话题结果；下拉刷新时保留已有结果直到新内容返回。
- 热搜右侧状态标签使用彩色圆角正方形和白字，「爆」为深红色；标签以服务器返回为准。

### 写微博、@提及与消息

- 写微博支持文字、表情、@提及和图片，可在编辑页选择可见范围后发送。
- 评论或编辑时输入 @ 可选择候选昵称；关注/粉丝索引尚未加载时需要等待。
- 离开编辑页可保留当前草稿；发布成功或切换账号后会清理对应编辑状态。
- 消息页使用微博移动网页，与应用共用登录态；部分行为与功能由微博网页提供。

### 设置与常见问题

- 自动隐藏底栏、显示评论点赞数、后台播放声音为独立开关。
- 表情同步可更新本地表情；图片清晰度可选省流、标准、高清，主要影响缩略图。
- 行距与字号可调整正文阅读效果；深色模式支持浅色、深色和跟随系统。
- 主题颜色提供九种配色，作用于导航、按钮和强调文字；关于页面显示当前安装版本。
- 内容加载失败可先下拉重试，登录失效则重新登录。删除本地账号不等于注销微博账号。
- 本应用为非官方客户端，接口变化、隐私限制或风控可能影响部分内容及操作。

## 数据与隐私

- 登录通过微博网页完成，应用使用登录 Cookie 调用微博接口；请将本地账号数据视为敏感信息。
- 时间线、用户资料、表情、媒体等会使用本地缓存；缓存不代表服务端永久可用，退出应用也不等于退出账号。
- 消息和部分链接使用网页，官方微博唤起及第三方页面取决于目标应用与链接支持情况。
- 点赞列表、照片、视频、评论等以当前账号有权读取的服务端内容为准；空列表不一定表示对方没有内容。
- 不要提交 Cookie、登录快照、签名私钥或 `keystore.properties` 到公开仓库。

## 开发与构建

使用 Android Studio 打开项目，配置 Android SDK 与兼容项目 Gradle/Android 插件的 JDK。SDK 路径通过本机 `local.properties` 配置，不应照搬其他电脑的路径。

项目使用 Kotlin、Jetpack Compose、Material 3 和 Media3 ExoPlayer。微博请求与解析主要位于 `data/`，页面、导航和交互主要位于 `ui/`。

### Windows 构建命令

```powershell
.\gradlew.bat :app:assembleDebug
.\gradlew.bat :app:testDebugUnitTest
```

### Release 签名与打包

复制 `keystore.properties.example` 为 `keystore.properties`，填写自己的签名文件及凭据，再执行：

```powershell
.\gradlew.bat :app:assembleRelease
```

输出：`app/build/outputs/apk/release/app-release.apk`。

Release 是否可安装及能否覆盖旧版本，取决于签名配置。不要使用他人的签名凭据，也不要将私钥上传到 GitHub。

### 主要源码位置

- `app/src/main/java/com/example/myweibo/MainActivity.kt`：应用入口与登录桥接。
- `app/src/main/java/com/example/myweibo/data/WeiboWebSession.kt`：微博会话与接口请求。
- `app/src/main/java/com/example/myweibo/data/WeiboJsonParser.kt`：微博、评论、链接与媒体解析。
- `app/src/main/java/com/example/myweibo/ui/WeiboApp.kt`：页面、设置、导航与播放交互。
- `app/src/main/java/com/example/myweibo/ui/theme/`：主题与字体。
- `app/src/test/`：本地单元测试。
